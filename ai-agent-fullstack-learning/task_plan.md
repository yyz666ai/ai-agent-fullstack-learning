## Decisions Made
| Decision | Rationale |
|----------|-----------|
| 严格以用户指定的 Harness PDF 顺序授课；代码目录只用于匹配实践 | 用户明确要求按该 PPT，从其第一个具体技术知识点开始 |
| 每次只讲一个可消化的小节 | 降低认知负担，便于用户实际运行和提问 |
| 进度记录保存在 Codex memory 的 ad-hoc notes | 用户明确要求跨次可查看的学习记忆，且不污染课程源码 |
